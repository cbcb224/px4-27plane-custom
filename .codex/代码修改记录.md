- 时间：2026-10-30（具体时分以 Git 提交时间为准）
- 提交说明：Fix USB CDC startup without VBUS sense

  - `boards/p224/p224-aio-v1/src/usb.c`

- 实际修改：
  - 删除从参考板继承的 `GPIO_OTGFS_VBUS`/PA8 定义。原理图中 PA8 为“无网络”。
  - 仅在存在 `GPIO_OTGFS_VBUS` 时才配置 VBUS 引脚。
  - 为本板提供 `board_read_VBUS_state()`，无 VBUS 检测脚时返回 `0`（已连接）。
- 修改原因：
  - NuttX 在未启用 `CONFIG_USBDEV_VBUSSENSING` 时会强制 OTG FS 设备会话有效，USB 控制器本身不需要 PA8。
  - PX4 `cdcacm_autostart` 仍调用 `board_read_VBUS_state()`。原配置读取悬空下拉的 PA8，持续报告 VBUS 不存在，因此不会执行 `sercon`，Windows 也看不到 CDC ACM 设备。
  - 该问题不影响 bootloader 的 USB 烧录路径，符合“bootloader 能烧录、应用启动后无串口”的故障现象。
- 验证：
  - GitHub Actions 云端构建待执行。
  - 必须烧录本次应用固件后，确认 Windows 出现 `VID_1B8C&PID_0036` 的 USB CDC 设备，并确认 QGC 可连接。
